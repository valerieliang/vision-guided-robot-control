# EEG Dataset Workspace

Place local public EEG datasets here. Raw datasets are intentionally not
committed because they are large and have citation/licensing requirements.

Expected layout:

```text
datasets/eeg/physionet_eegmmi/
datasets/eeg/bci_comp_iv_2a/
```

The registry in `neurotech/datasets.py` records the official URLs and local
directory names.
